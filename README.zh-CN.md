# VistaV：GTA V 护眼均衡 ReShade 滤镜

[English](README.md) | **简体中文**

VistaV 是一个为**原版 GTA V**（增强版和传承版）编写的单文件 ReShade 效果，目标是让你能长时间游玩：曝光稳定、影调均衡、夜晚和雨天看得清、泛光收敛、锐化不刺眼。

它**不需要深度缓冲**，也**不依赖任何游戏 mod**，所有处理都只基于最终画面。

## 功能概览

| 原版 GTA V 的问题 | VistaV 的处理 |
|---|---|
| 画面里出现一个亮点（车灯、路灯），游戏的自动曝光就把整个画面压暗 | **反自动曝光**：统计背景亮度时排除光源。游戏压暗过头时，通过保护高光的曲线把曝光补回来：暗部被提亮，车灯和被照亮的表面基本保持原本亮度。 |
| 夜晚（含雨夜）又暗又灰，看不清 | **局部暗部提亮**：只提亮暗区域，统计时排除光源，灯周围不会出现黑圈。**自适应清晰度**：大半径局部对比度，画面发灰（雨、雾、夜）时自动加强。 |
| 泛光要么平淡，要么把整个屏幕泛白 | **泛光金字塔**：13 点下采样、Karis 平均（抑制雨滴反光闪烁）、柔和阈值、白天自动提高阈值、雾化抑制、夜间眩光抑制。 |
| 夜晚车灯刺眼 | **夜间眩光抑制**：夜晚只压暗最亮的像素，白天自动淡出。 |
| 后期处理让 HUD 文字发光、干扰测光 | **HUD 区域**：小地图和通知区域不发光、不参与曝光统计；文字边缘做不产生白边的锐化。这片区域的影调与屏幕其它地方完全一致，不会出现色块。 |
| 转镜头时画面显得生硬 | **动态模糊**（可选）：画面分成 160×90 块，每块与上一帧比对，得到逐区域的运动场，再沿运动方向做轻度模糊。跟着镜头一起动的东西——你的角色、你的车、HUD——会被识别为静止，保持清晰。 |

效果界面**自动切换语言**：ReShade 界面是中文时显示中文，其他语言时显示英文。这是借助 ReShade 自带的本地化字段（`ui_label_zh`、`ui_tooltip_zh` 等）实现的。

## 环境要求

- GTA V 增强版（DX12）或传承版（DX11）。已在增强版上测试。
- [ReShade](https://reshade.me) **6.0 及以上**（本地化界面字段需要 6.x）。已在 6.8.0 上测试。
- 附带的预设还要用到 ReShade 官方仓库里的两个效果，都可以在 ReShade 安装器里勾选：
  - `AdaptiveSharpen.fx`（*Standard effects*）
  - `ColorMatrix.fx`（*SweetFX by CeeJay.dk*）

  VistaV 本身除了 `ReShade.fxh` 之外没有其他依赖。

## 安装

1. 为 `GTA5_Enhanced.exe`（传承版为 `GTA5.exe`）安装 ReShade，图形 API 选 DirectX 12（传承版选 10/11），效果包勾选 *Standard effects* 和 *SweetFX*。
2. 把 `reshade-shaders/Shaders/VistaV/VistaV.fx` 复制到 `<游戏目录>\reshade-shaders\Shaders\VistaV\`。
3. 把 `presets/VistaV_Comfort.ini` 复制到游戏目录。
4. 进游戏打开 ReShade 菜单，在预设列表里选 `VistaV_Comfort.ini`。

预设的效果顺序是 **`VistaV → ColorMatrix → AdaptiveSharpen`**，VistaV 必须放在最前面。

## GTA Online

VistaV 在故事模式和 **GTA Online** 中都可以使用（已在开启 BattlEye 的情况下测试）。它不使用深度缓冲，所以不受 ReShade 在联网游戏中对深度缓冲的限制。请使用标准版 ReShade；*完整插件支持（full add-on support）* 版本只适用于单机游戏。

## 工作原理

全部处理都在线性空间、用 16 位中间纹理完成，所以提亮暗部不会产生 8 位色带。最终输出带抖动。

1. **测光**：在 1/4 分辨率下计算 `log2` 亮度。高光权重接近 0，所以测到的是"背景"亮度。再用 256×256 的 mip 链求出整帧的加权对数平均和对数标准差（即对比度）。可选画面中心加权，HUD 区域不参与统计。
2. **适应**：算出把背景拉到「目标背景亮度」所需的增益，乘以暗场景/亮场景补偿强度，限制在上下限内，再用与帧率无关的指数滤波做时间平滑。
3. **保护高光的增益**：增益通过 `f(m) = G·m / (1 + (G−1)·m^q)` 作用在 `max(RGB)` 上。`q ≤ 1` 时这条曲线单调递增，黑色附近接近完整增益，并且 1.0 仍映射到 1.0。`q` 由「高光保护」控制。
4. **局部暗部提亮**：用 1/16 分辨率、高斯模糊过、排除了高光的局部背景亮度，只给暗像素额外提亮。因为局部均值里不含光源，灯周围不会出现黑圈。
5. **清晰度**：放大像素相对同一局部背景的对数偏差，只作用于中间调。测到的整帧对比度越低，强度越高。
6. **泛光**：先把接近纯白的像素还原成伪 HDR 能量，再用带 Karis 平均的 13 点预滤波、随白天程度缩放的柔和阈值、7 级金字塔加帐篷上采样，最后做雾化抑制 `b·Y/(Y+h)` 和夜间缩放。
7. **动态模糊**：先估算一个粗略的全局镜头运动：取 1/32 分辨率亮度，并行评估 169 个候选位移，用 mip 第 3 级归约，再用抛物线拟合细化。然后在 1/16 分辨率下建立**逐区域运动场**：在 1/8 分辨率亮度上做候选搜索（类似 3-D recursive search）。每块依次测试零位移、全局运动、上一帧本块及 4 个相邻块的运动，再做 ±1 和 ±0.5 纹素的细化，并带一点时间一致性惩罚。之后用 3×3 矢量中值去除离群值，同时保留物体边界。模糊时沿局部运动方向取 4~16 个抖动采样，**只接受和中心像素运动相近的采样**，所以屏幕上静止的物体既不会被模糊，也不会拖进背景里。
8. **影调**：白平衡、指数肩部压缩、夜间最高亮度压暗、暗部/高光、带暗部保护的轻度 S 曲线、自然饱和度/饱和度、冷暖分离、输出色阶、可选暗角、三角分布抖动。

## 参数说明

下表的默认值与 `VistaV_Comfort` 预设一致。

|---|---|---|
| 目标背景亮度 | 0.08 | 希望背景（线性对数平均）达到的亮度，越大夜晚越亮。 |
| 暗场景补偿强度 | 0.40 | 场景过暗时向目标靠拢的比例。 |
| 亮场景压暗强度 | 0.30 | 场景过亮时向目标靠拢的比例。 |
| 最大提亮 / 最大压暗 | 2.0× / 0.8× | 增益上下限。 |
| 高光排除阈值 | 0.25 | 亮于此值的像素不参与测光。 |
| 画面中心权重 | 0.40 | 测光偏向屏幕中心的程度。 |
| 适应速度 | 1.5 | 越低越平稳，越高反应越快。 |

| 文字锐化 | 0.4 | 结果被限制在 3×3 邻域的明暗范围内，不会产生白边。 |

### 7. 调试
- **分屏对比**：左边原图，右边效果。
- **提亮倍数热力图**：每个像素的总曝光变化（蓝 = 压暗，绿 = 不变，红 = 提亮，范围 ±2.5 档）。
- **只看泛光**。
- **测光遮罩 + 数值条**：蓝色是被排除在测光外的高光，红色是 HUD 区域。左上角数值条依次是：全局提亮（红线代表 1×）、画面对比度、白天程度、全局运动估算可信度、镜头速度。
- **运动矢量**：颜色代表运动方向，饱和度代表速度（每帧 48 像素时最饱和），可信度越低越暗。

| 定义 | 默认值 | 作用 |
|---|---|---|
| `VISTAV_STREAK` | 0 | 设为 1 时编译横向光晕。 |
| `VISTAV_MOTIONBLUR` | 1 | 设为 0 时移除所有动态模糊相关计算。 |

## 附带的预设

`presets/VistaV_Comfort.ini` 设置好了效果顺序，并为配套效果设置了以下参数：

- **ColorMatrix**：`Red (0.80, 0.18, 0.00)`、`Green (0.335, 0.67, 0.00)`、`Blue (0.15, 0.07, 0.87)`，强度 1.0。这组矩阵把一部分红色混进绿色，用来压掉 GTA 自带的黄绿色调。请确认 `reshade-shaders\Shaders` 下只有**一个** `ColorMatrix.fx`。有些安装会在根目录和 `SweetFX\` 里各放一份，ReShade 就会把它执行两次。
- **AdaptiveSharpen**：强度 0.15，并减小了过冲（`D_overshoot 0.006`、`scale_lim 0.07`），锐化后不刺眼。

## 推荐的游戏内设置

- 游戏亮度保持默认，曝光交给 VistaV 处理。
- **帧生成**：补出来的帧可能不经过 ReShade，于是有滤镜和没滤镜的帧交替出现。如果看到闪烁（录屏里尤其明显），先关掉帧生成测试，或者改用 NVIDIA Smooth Motion 这类驱动层补帧。
- 如果画面刺眼，把游戏里的 **DLSS / FSR 锐化**调低（例如 0.2~0.3）。它会和 AdaptiveSharpen 的锐化叠加。

## 常见问题

- **编译失败**：查看游戏目录下的 `ReShade.log`，带上报错那一行提 issue。
- **HUD 区域位置不对**：打开「测光遮罩 + 数值条」调试视图，调整「区域左上角 / 右下角」。默认值按 16:9 和默认 HUD 安全区设置。
- **不该模糊的时候出现模糊**：调高「死区」或调低「强度」。天空这类没有纹理的画面会被自动忽略。
- **OBS 录制画面闪烁**：OBS 的「游戏采集」和 ReShade 都要挂进游戏的画面输出，可能导致录到的画面在有/无滤镜之间交替（[obs-studio#11250](https://github.com/obsproject/obs-studio/issues/11250)）。改用「显示器采集」，或使用 NVIDIA App 自带的录制。
- **颜色像是被处理了两遍、过浓**：确认 `reshade-shaders\Shaders` 下只有一个 `ColorMatrix.fx`。

## 性能

使用 ReShade 的「统计」页面实测，2560×1440、RTX 4070、GTA V 增强版、完整 `VistaV_Comfort` 预设，169 FPS：

| 效果 | GPU 耗时 |
|---|---|
| VistaV（32 个 pass） | 约 1.27 ms |
| ColorMatrix | 约 0.09 ms |
| AdaptiveSharpen | 约 1.01 ms |
| 整套效果链 | 约 2.36 ms |

VistaV 只有两个 pass 是全分辨率（曝光处理和最终合成），其余都在 1/2 到 1/128 分辨率下运行，或者只用很小的纹理。动态模糊按模糊长度使用 4~16 个采样，低于死区的像素直接跳过。参数调好后，建议打开 ReShade 的**性能模式**，关掉的功能会在编译时被去掉。实际耗时随显卡和场景变化。
